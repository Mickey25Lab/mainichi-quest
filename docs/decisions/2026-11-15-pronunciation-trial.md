# 発音お試しモード（13語・実験）
日付：2026-11-15
状態：試行中（正式学習モードではない）

## 入口と対象
- iPad Safari / PWAのブラウザで、Cloudflare Preview の `/pronunciation-trial.html` を直接開く。既存モード選択・報酬導線には追加しない。
- 現行mainの「えいごのことばをよもう」基本名詞は14語。今回指定の13語を検証するため先頭13語（BED / BOX / CAT / DOG / LEG / MAN / MEN / PIG / SUN / TOP / HAND / MILK / NEST）を固定順で使用し、WINDは暫定除外する。
- 対象13語が正式な13語と異なる場合は実機実験前に更新する。

## 手順
1. 単語の小文字・大文字を既存カードと同様に表示する。
2. 「よんでみる」を押してブラウザ標準音声認識（Web Speech API、en-US）を起動する。
3. 発話後のブラウザ標準の自動認識終了イベントで、認識文字列を表示して親判定へ自動遷移する。「よみおわったよ」の手動ボタンは置かず、親判定との連続誤タップを防ぐ。認識値が一致しても発音の正誤と同一視しない。
4. おうちの人が赤い○「発音が合っている」／青い×「発音が間違っている」／オレンジの△「曖昧・ノイズあり」の3択で評価すると次の単語へ。判定ボタン内のラベルは折り返さない。
5. 13語完了後に「出題単語／iPadの認識結果／文字正誤／親判定」の4列をまとめて表示。文字正誤は大文字・小文字を区別せず、単語が一致なら○、異なれば×（認識なし・エラーも×）。スクリーンショットで共有する。

## 制限・安全
- 追加の有料API契約なし。ブラウザ内蔵の認識機能を使用。ブラウザ・端末・ネットワークにより利用不可の場合がある。音声データがブラウザ実装のサーバーに送られる可能性はある。
- 認識エラー・非対応も記録可能で、親判定に進める。
- 文字列・評価・録音はサーバーへ送信せず、localStorage等へ保存もしない。画面終了で破棄。
- 既存プレイヤー保存・学習履歴・報酬・日次進捗には一切触れない。
- 実機検証ではマイク権限、PWA/Safariの認識対応、自動終了直後の確定認識、13語の表のスクリーンショット適合を確認する。
