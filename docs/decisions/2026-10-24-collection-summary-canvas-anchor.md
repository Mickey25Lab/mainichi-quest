# 決定: コレクションサマリの画像キャンバス下端を共通基準にする

日付：2026-10-24
状態：試行中（PR Preview確認待ち）

## 状況
従来のサマリカードは `.vehicle-area` のグリッド配置、`object-fit:contain`、`align-self`、`transform:translateY(-9px)` と段階別拡大を重ねていた。画像キャンバスの下端と名前ラベル上端の位置関係が一つの数値で定義されておらず、位置調整の効果が読みにくかった。

## 決定
- 画像の**透明部分を含むキャンバス全体**で位置を決める。可視アルファ境界の測定・車種ごとの位置補正・倍率補正は禁止する。
- 全車種・未発見シルエット・全段階で同じ計算式：**画像キャンバスの下端 = 名前ラベル上端 − bottomOffset**（正で上、負で下）。
- キャンバスは全車種共通の正方形比率。画像ボックスを `position:absolute` で配置し、`bottom` と `transform-origin:center bottom` で基準点を固定する。拡大時も下端が動かない。
- キャラクター表示領域の `bottom:38px` は名前ラベルの `bottom:8px; height:30px` に合わせる。名前ラベルを `z-index:8` で手前に置く。
- 調整可能な値は**段階別の scale と bottomOffset のみ**。ロジックは一つで、段階別なのは数値だけ。
- Preview初回レビュー後の調整パラメータ（iPadで再検証）：

| 段階 | scale | bottomOffset |
| --- | ---: | ---: |
| 未発見・乗り物（2） | 50% | +10px |
| ロボット（3） | 50% | +10px |
| スーパーロボット（4） | 70% | 0px |
| スーパー装備（5） | 85% | 0px |
| マスターメダル到達 | 70% | 0px |

- 既存の装備アイコン・メダル背面配置・エネルギーゲージ・ハート配置は維持する。
- 一部の大型キャラクターがカード外でクリップされることは許容する。カード以外の親に追加のクリップ領域を設けない。

## 理由
全素材が同じキャンバスで制作されているという制作基準を利用し、画像の下端と名前ラベルの位置関係を明示する。複数のCSS位置決めの組み合わせを撤去する。

## 影響
`dist/styles.css` の **コレクションサマリ限定** CSS。画像素材、描画DOM、保存データ、進化計算、問題画面、詳細画面、versionは変更しない。

## 見直し条件
PR PreviewをiPadで確認し、必要に応じて段階別 scale・bottomOffset だけを調整する。画像ごとの例外は許可しない。

## 2026-10-24 Preview初回フィードバック
下端アンカー方式への変更により、旧グリッド内での `object-fit:contain` による縮小がなくなり、正方形キャンバスに旧倍率を掛けた結果、各段階が極端に大きく表示された。配置ロジックは維持し、倍率と整数pxのオフセットだけを上表のきりのよい値へ修正。以後の調整も整数%／整数pxを使う。
