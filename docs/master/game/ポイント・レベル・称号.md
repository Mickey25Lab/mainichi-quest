## ポイントの内訳

ポイントは車種ごとの進行を永続記録する。過去に得たポイントを、後から設定変更で再計算して減らさない。

| 進行 | ポイント |
| --- | ---: |
| のりもの発見 | 5 |
| なかよしハート | 1個につき2（最大10） |
| なかよし達成 | 10 |
| 各進化段階の満了 | 必要エネルギーと同額の進化ボーナス（30、50、100、200） |
| 保有エネルギー | 現在値を加算（進化時は次段階へリセット） |
