## エネルギーカプセル

| 項目 | 現在の仕様 |
| --- | --- |
| 効果 | 選んだ、発見済みかつなかよし済みの車種へエネルギーを **20** 加える。満了すれば進化する。 |
| 入手 | 新しいレベル到達ごとに1個。初回に既存ポイントがある利用者へは遡って配らない。 |
| 所持上限 | 99個 |
| 使用対象 | 発見済み、かつなかよし済みの車種 |
| 選択時間 | 30秒。時間切れ時は対象からランダムに選ぶ。 |

カプセル消費と報酬進捗の保存は一体で行い、保存失敗時にカプセルだけを失わない。将来の新アイテムは、仕様・数値・入手条件をこの文書と同じPRで更新する。
