# コレクション・進化

状態：実装済み  
コード参照先：`dist/app.js` の `acquisitionDefinitions`、`requiredEnergyForStage`、`renderCollectionGrid`、`renderVehicleDetail`

## 進化段階と条件

| 段階 | 得られるもの | 条件 | 必要エネルギー |
| ---: | --- | --- | ---: |
| 1 | のりもの発見 | 未発見の車種で最初の正解 | — |
| 1 | なかよし | 発見後、ハート5個 | — |
| 2 | ロボット | なかよし後のエネルギー満了 | 30 |
| 3 | スーパーロボット | 次段階のエネルギー満了 | 50 |
| 4 | スペシャル装備 | 次段階のエネルギー満了 | 100 |
| 5 | マスターメダル | 次段階のエネルギー満了 | 200 |

発見と、なかよしまでのハートは車種ごとに保存する。進化が起きると、その車種チャレンジは終了して次の車種へ移る。詳細な加算条件と例外は [`報酬体系.md`](報酬体系.md) を正とする。

## コレクション

20車種を、乗り物・ロボット・スーパーロボット・装備・メダルのカテゴリで閲覧する。固定IDと表示順は [`車種マスタ.md`](車種マスタ.md) を正とする。未発見はシルエット表示、発見後は進行状況とNEW／UP表示を行う。

## マスターメダル獲得演出（Stage 5）

獲得画面は既存のコレクション詳細構成を再利用する。車種の背景・左上ロゴ・乗り物／ロボット／スーパーロボットは、既存のネイビー半透明 `reward-dimmer` の背面に配置し、マスターメダルとそのホログラム台座だけを暗幕の前面に表示する。既存の「マスターメダル GET」画像も最前面に表示し、従来位置から画面基準で右に約100px（1400px幅基準）、従来比85%に縮小する。獲得画面では中央下の車種名・レアリティ・星表示を行わない（他段階の表示は維持）。新規画像・保存データ・報酬条件は変更しない。

実装参照先：`dist/app.js` の `buildStage5CollectionComposition`、`showReward` と `dist/styles.css` の Stage 5 獲得画面スタイル。
