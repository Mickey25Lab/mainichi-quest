## 数値の扱い

ゲームバランスの数値は、人が検討できるよう正式MDにも表で載せる。ただしアプリを実際に動かす正本はコードであり、各表にはコード上の参照先を記す。数値変更ではコードとMDを同じPRで更新する。コードからMDを自動同期する仕組みは検討中であり、今回のPRには含めない。
