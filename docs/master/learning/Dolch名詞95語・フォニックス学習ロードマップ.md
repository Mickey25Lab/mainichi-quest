# Dolch名詞から選ぶ94語｜フォニックス学習ロードマップ・モード設計（家庭内MVP）

更新日：2026-11-08
状態：**導入5語は実装済み／基本A＋基本Bの14語モード以降は設計案**（本書は仕様整理。アプリコードは変更しない）
対象：マイクエ「フォニックスでよんでみよう」および後続の単語学習、口の形レッスン

## 0. 目的・実装方針

- **英語教材を完璧に制作することは目的としない。** 子どもが英語を読める・音をまねられる・意味が分かる体験を優先する。
- ミナトはA〜Zの基本26音を習得済み。既存の導入5語モードで1文字ずつ音をつなぐ体験を行う。**次に作る14語モードは基本A＋基本Bの全14語（導入5語を含む）**を単語単位で「自分で読む→英語のお手本音声を聞く→まねして言う→意味を確認」の流れで練習する。
- ルール説明は日本語（ひらがな中心）とカタカナで**一言**。カタカナは音の目安であり正確な英語音声の代わりではない。新しい音声素材は原則制作しない。
- 既存YouTubeの**区間再生（フォニックスその1〜5で利用中の仕組み）**を再利用できるルールのみ短い映像・音を使う。それ以外はテキスト表示と**単語そのものの英語TTS**でよい。
- 意味は絵を基本に、抽象語・多義語など絵だけでは伝わりにくい場合には日本語を添える。**意味を見せるのは原則読みの後**。
- 音声認識・AI発音判定・自動正誤判定を入れず、自己申告「いえたよ」を使う。音素単独のIPA発音をブラウザTTSに要求しない。
- 口・舌の動きが重要な音は、**別の「くちのかたちレッスン」**で動画／断面図／インカメラを使う。
- 実装順：①導入5語モード（完了）→②基本A＋基本Bの14語モードを作る→③以降の語群・口の形レッスンを段階的に追加。

## 1. 導入モード「フォニックスでよんでみよう」（実装済み）

- 出題語：**CAT / DOG / SUN / BOX / PIG** の5語。すべてDolch名詞・3文字。
- 1文字ずつ音を確認し、つなげて単語を読む体験をする導入モード。
- 単語全体の英語音声、意味イラスト、自己申告「いえたよ」、既存の報酬・育成導線を使用する。
- 現行仕様は `docs/master/learning/フォニックスでよめることば.md` を参照。

## 2. Dolch名詞から選ぶ94語の全体像と段階別一覧

Dolch名詞の公式95語から、家庭での使いやすさを優先して**ROBINを対象外とした94語**を使う。以下の「基本A〜B／1A〜1D／2A〜2B／3A〜3D」は**マイクエ独自の学習順**。単語の意味・発音の地域差・例外を厳密に教え尽くすための分類ではない。表の94語は各1回掲載。**次に作る単語学習モードは基本Aと基本Bを合わせた14語を、導入5語を含めてすべて単語単位で練習する。**

| レベル | 習得の目安・代表ルール | 全単語 | 語数 |
|---|---|---|---:|
| 基本A | 3文字・短母音 | BED, BOX, CAT, DOG, LEG, MAN, MEN, PIG, SUN, TOP | 10 |
| 基本B | 4文字・既習音の連結 | HAND, MILK, NEST, WIND | 4 |
| 1A | Magic E／長母音 | CAKE, GAME, NAME, HOME, TIME | 5 |
| 1B | 母音チーム EE EA OA AI AY OY OW EAR | BOAT, COAT, FEET, SEED, STREET, TREE, RAIN, DAY, WAY, BREAD, HEAD, BEAR, BOY, TOY, SNOW | 15 |
| 1C | R-controlled AR ER IR OR | CAR, FARM, FARMER, BIRD, GIRL, CORN, HORSE, PAPER, SISTER | 9 |
| 1D | 二重母音 OW OU（/aʊ/） | COW, GROUND, HOUSE, FLOWER | 4 |
| 2A | 子音の連字 CK SH CH TH NG（既習の母音ルール併用） | BACK, DUCK, STICK, FISH, CHAIR, BROTHER, FATHER, MOTHER, THING, RING, SONG, BIRTHDAY, SHEEP, MORNING | 14 |
| 2B | 追加の綴り ALL OOR IGH 子音+LE OW | BALL, DOOR, FLOOR, NIGHT, TABLE, WINDOW | 6 |
| 3A | 弱母音・音節の変化 | APPLE, CHICKEN, CHILDREN, GARDEN, SQUIRREL | 5 |
| 3B | 語末Y・単独文字の別の読み／母音の例外 | BABY, KITTY, PARTY, MONEY, WATER, WOOD | 6 |
| 3C | 二重子音・音節の区切り | BELL, DOLL, EGG, GRASS, HILL, LETTER, RABBIT | 7 |
| 3D | 特殊な綴り／不規則語 | EYE, FIRE, GOOD-BYE, PICTURE, SCHOOL, SHOE, WATCH, CHRISTMAS, SANTA CLAUS | 9 |
| **計** | **基本14／グループ1＝33／グループ2＝20／グループ3＝27** | | **94** |

**注意**
- 「基本26音のみ」は家庭向けの概算。例えば BOX の X は /ks/、DOG の母音はアクセント差がある。5語導入以外の分類は学習上の目安とする。
- グループ1は母音関連ルールをまとめている。**母音チームは長母音と同義ではない**（BREADのEA、BOYのOYなど）。
- 2B・3A〜3Dも一部に母音・子音の複数文字の知識を要する。**全ルールの習得を保証する厳密な依存関係表ではない。** 例えば SANTA CLAUS は一つの語彙項目として1件。
- **単語を見て音を出す練習（decoding）**と**音声を聞いてまねする練習**を両方用意する。完全な丸暗記だけにしない。

## 3. 指定YouTubeの収録ルール・不足ルール

### 3.1 指定素材と運用

- 指定動画／プレイリスト： https://www.youtube.com/watch?v=r105Re__0L0&list=PLfTWSlY6VnCE
- **収録済みと扱う音（ユーザー申告）**：
  - CH「チ」、PH「フ」、SH「シ」、TH（無声）「ス」、TH（有声）「ザ」
  - OO（短いウ）、OO（長いウー）
  - AR「アー」、ER「アー」、IR「アー」、OR「オア」、UR「アー」
  - TION「ション」、SION「ション」、SION「ジョン」
- 上記カタカナは**ユーザーの手元メモ**であり発音記号ではない。SH、TH、Rなどは日本語の音と同一ではない。
- 既存フォニックス動画モードの**YouTube IFrame区間再生処理を再利用**。該当動画の開始秒・終了秒（1〜数秒程度）は実装時に実際のプレーヤー動作を確認して登録する。**本書では秒数・動画内部の収録位置を推測しない。**
- 動画にない音は無理に探さず短い日本語・カタカナ説明のみ。例：`ee で「イー」にちかい音`、`ay で「エイ」にちかい音`、`ck で「ク」にちかい音`、`ng で「ング」にちかい音`。英語の単語全体のTTSは使う。
- PH / TION / SION は対象の94語で直接必要な代表ルールではなく**後回し可**。

### 3.2 レベルごとの対応／不足

| レベル | 必要な代表ルール | 指定動画でカバー | 動画にないもの／短文説明で対応 |
|---|---|---|---|
| 基本A〜B | 既習の基本26音、短母音、子音連続 | 導入には原則不要 | 必要ならX=/ks/。次の14語モードでは1文字送りなし |
| **1A** | Magic E、A_E / I_E / O_E | **なし** | 最後のeは読まず前の母音を長く／アルファベット名に近く読むことがある |
| **1B** | EE、EA（BREAD/HEADは「エ」）、OA、AI、AY、OY、OW（SNOW）、EAR（BEAR） | **なし** | ee「イー」、ea「エ」の場合、oa「オウ」、ai/ay「エイ」、oy「オイ」、ow「オウ」、ear「エア」に近い音 |
| **1C** | AR、ER、IR、OR | **AR / ER / IR / OR** | 既存動画で概ね対応。HORSE・PAPER等の組み合わせは単語音声で確認 |
| **1D** | OW / OU（COW、HOUSE等の「アウ」） | **なし** | ow / ou で「アウ」に近い音 |
| **2A** | CK、SH、CH、TH、NG＋1群の母音規則 | **SH / CH / TH（2音）** | CK「ク」、NG「ング」。SHEEPのEE、CHAIRのAIR、BIRTHDAYのAYなどは1群と組み合わせる |
| **2B** | ALL、OOR、IGH、子音＋LE、OW（WINDOW） | **なし** | all、oor、igh、-le、ow をそれぞれ一言で説明。OW（オウ）は1Bで扱える |
| **3A** | 弱母音・音節の変化、複雑な語形 | **CH（CHICKEN等）** | 弱く読む母音・音節の区切り・語ごとの発音は単語TTSで確認 |
| **3B** | 語末Y、OOの短い音、例外的な母音 | **OO（短／長）** | 語末yが「イー」に近い音、MONEY・WATER等の例外は単語ごと |
| **3C** | 二重子音LL / GG / SS / TT / BB | **なし** | 同じ子音が続いても2回発音しないことが多い／単語音声で確認 |
| **3D** | TCH、TURE、CH=/k/、OEなど特殊な綴り | **CH（基本の/ tʃ /のみ）** | SCHOOL / CHRISTMASのCH=/k/、WATCHのTCH、PICTUREのTUREなどは個別の短文＋単語TTS |

- **別途口の形レッスンとして優先**：TH、F/V、R/L、SH/S、CH/J。F、V、L、S、JはDolch95語の分類表の見出しと独立して学べる。
- 単語TTSは`speechSynthesis`の英語音声を使用。**IPA記号だけを入力して英語の単独音を確実に再生できるとはみなさない。**

## 4. 学習モード設計

### 4.1 導入5語（実装済み）

- CAT / DOG / SUN / BOX / PIGを1文字ずつ確認し、音をつなげて単語を読む体験をする。
- 「きいてみる」で単語全体の英語音声を聞き、イラストを確認して「いえたよ」で進む。報酬・育成導線を維持。

### 4.2 次に作るモード：基本A＋基本Bの14語

**対象：BED / BOX / CAT / DOG / LEG / MAN / MEN / PIG / SUN / TOP / HAND / MILK / NEST / WIND（計14語）**

1. **この14語すべて**を一つのモードで練習する。導入モードにある5語も含む。
2. 単語を大きく提示する。意味・イラストは最初は隠す。
3. 子どもが**単語を一気に自分で読んでみる**。1文字ずつ音を進める操作は行わない。
4. 「きいてみる」で英語の**単語全体**の音声を聞き、まねして言う。
5. イラストを表示し、必要な単語には日本語の意味を添える。
6. 「いえたよ」で次へ。音声認識・自動採点はしない。
7. 出題順、1回の問題数、日次設定、報酬との接続は実装前に決める。

### 4.3 ルール導入（短く・必要時のみ）

- 初めてのルール：`sh は「シュ」にちかい音だよ`程度の**ひらがな／カタカナ一文**。
- 指定YouTubeで対応可能なルールのみ、**既存区間再生**で実際の音を短く聞く。その他は文字の説明を読んで、そのルールを含む**単語のお手本音声**を聞く。
- 毎問ルールを強制再表示しない。復習の導線は後で決める。
- 正確な発音は単語TTS／該当動画を優先し、カタカナだけで練習を完結させない。

### 4.4 意味表示（語ごとの重みづけ）

| 種類 | 例 | 表示方針 |
|---|---|---|
| 絵でほぼ伝わる | CAT / DOG / APPLE / SHEEP | 絵を中心にする |
| 絵だけでは曖昧・抽象的 | THING / TIME / WAY | 絵＋日本語（「もの」「じかん」「みち／ほうほう」など） |
| 複数の意味がある | WIND / RING / WATCH | 対象の意味を固定し、絵と日本語の一致を確保 |

- 画像は**読みのヒントを先に出さない**方針。既存単語画像の権利・出典表示を維持する。
- 単語データには語形、読み上げ表記、意味（日本語）、イラストパス、ルールID、レベル、意味表示区分の追加を検討。未承認の保存形式変更を行わない。

## 5. 独立した「くちのかたちレッスン」（別途実装）

**目的**：英語の手本の音と、自分の口・舌の使い方を結びつける。通常の単語学習には毎回挟み込まない。

| 優先 | 音のセット | 教える動き | 推奨媒体 |
|---|---|---|---|
| 最優先 | **TH（無声／有声）** | 舌先と上の前歯付近、声の有無 | 正面＋横断面／インカメラ |
| 最優先 | **F / V** | 上の前歯を下唇に軽く当てる（強く噛まない）、声の有無 | 口元の正面・斜め動画＋インカメラ |
| 高 | **R / L** | Rは舌を歯茎につけず、Lは舌先を上の歯茎付近へ | **舌の断面図・アニメーション**＋補助的にインカメラ |
| 高 | **SH / S** | 唇・舌の位置と息の違い | 正面動画＋インカメラ |
| 高 | **CH / J** | 舌と息を止めてから出す動き、声の違い | 正面／断面動画＋インカメラ |
| 任意 | W、NG、短母音の口の開き、P/B・T/D等 | 唇の丸め方、鼻音、口の開き・声の有無 | 必要になったら追加 |

**レッスン構成**：
1. 口元の短い手本を再生（使える既存YouTube区間や適切な素材）。
2. 必要な音は舌の位置がわかる断面図を表示（インカメラだけで舌の奥は見えない）。
3. 子どもが希望するときのみインカメラを許可して開き、手本と見比べる。
4. 自分で発声して「できたよ」で終える。**録画・保存・アップロードなし／AI評価なし**。
5. カメラ非対応・権限拒否時も手本視聴だけで終了可能。

## 6. 音声・技術・プライバシーの方針

- 現行Web Speech APIの英語TTSは**単語全体**用。発音記号`ŋ`等を直接指定して単独音の発声を保証することはできない。
- 独立した英語音素の音声が必要になった場合も、まずは既存YouTube区間を使う。新規録音／課金APIは当面不要。
- iPad Safari／PWAでは音声開始のユーザー操作条件、再生タイミング、動画シークの精度を実機確認する。**YouTubeを指定秒で正確に1秒だけ再生できることは保証しない。**
- 音声認識・外部STT・AI採点を導入しないため、現時点で**文字起こしのAPI従量料金は発生しない設計**。標準TTSも追加の外部音声APIを必要としない。
- インカメラは明示的な操作と権限許可を必須にし、画面への表示のみ。子どもの顔・声を記録・送信しない。
- 進捗や報酬の既存プロフィール別保存を尊重し、データ消去・構造変更を勝手に行わない。

3. 既習ルールの説明をいつ再表示するか、任意の音のまとまりヒントの採否。
4. YouTube区間ごとの**開始・終了秒**と実機での再生検証（既存素材の再利用であり新規検索は必須ではない）。
5. 対象94語の各語に紐づける意味・表示画像・英語読み上げの語義（例：WINDは風、WATCHは名詞）、権利・素材の検証。
6. 一部の語の例外的発音やアクセント差は、**一言ルールだけで誤解が生じる場合に限り**個別調整する。
7. 口の形レッスンの動画／断面図素材、カメラの許可導線、親設定と新規プロフィール初期値、端末別サポート範囲。
8. 14語モード実装時は出題・達成判定・報酬の整合と既存プロフィールへの非破壊性をスモークテストする。
