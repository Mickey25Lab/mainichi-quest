# フォニックスでよめることば（家庭内MVP）

更新日：2026-10-31
状態：実装プレビュー・実機検証待ち

## 目的
学習済みのA〜Zの基本26音が「英語を読む」ことにつながる実感を得る。正誤判定や採点はしない。

## 対象と出題順
- 1〜5問：CAT / DOG / BED / BOX / LEG をランダム順
- 6〜8問：HAND / MILK / WIND をランダム順
- 9〜10問：PLANT / PICNIC をランダム順
- 10問とも重複なし・大文字。PICNICも含めて1文字ごとに進行。
- WINDは名詞「風」の /wɪnd/ を使用。

## 画面
1. 単語1文字ずつに同一サイズの文字枠を割り当て、現在位置だけ水色の角丸背景で強調。
2. 各「つぎへ」タップで次の文字へ。最後の文字から次へ進むと、同じ文字列の上端・下端・左右端に合わせた、文字列全体を包む一つの水色角丸背景に切り替える。
3. ボタンは同一位置・同一サイズで「つぎへ」→「きいてみる」→「いえたよ」。音声は「きいてみる」タップ時に、iPadの標準Web Speech APIでen-USの単語を1回だけ発声する。
4. 「きいてみる」タップから1秒後、単語を表すイメージを右に出す。次のカードへ進むと消える。画像は事前のヒントにならないよう、カード開始時は非表示。
5. 「いえたよ」は自己申告の進行ボタンで、正誤判定はしない。
6. 全10語を終えたら既存フォニックスと同じ、車種育成のサーチライト・報酬選択導線につなぐ。途中退出は達成に計上しない。

## 素材
家庭内の早期試作では単語の絵を端末標準の絵文字ピクトグラムで仮置きする。専用の単語イラストやアプリ世界観に合わせた素材の制作は不要で、後に入れ替え可能。**専用画像10点の配備は未完了。**

## 保護者設定
追加モード `phonics-words` は既存プロフィールの日次目標を勝手に増やさないため初期OFF。保護者設定「おうちの人へ」で1回以上に変更すれば利用可能になる。

## 変更範囲
- `dist/scripts/phonics-words.js`：カード順、読み上げ、表示・進行
- `dist/app.js`：親モード定義と達成・育成への接続
- `dist/index.html`：モード選択とスクリプト読み込み

子どもの既存の保存キーや育成データの形式は変更しない。
