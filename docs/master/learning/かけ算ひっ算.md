# かけ算ひっ算

状態：実装済み  
コード参照先：`dist/app.js` の `makeMultiplicationQuestions`、`makeTwoDigitMultiplicationQuestions`

| モード | 内容 | 問題数 |
| --- | --- | ---: |
| 2桁×1桁 | 2桁×1桁から4桁×1桁 | 10 |
| 2桁×2桁 その1 | 一の位→十の位→たし算の手順ガイド付き | 5 |
| 2桁×2桁 その2 | 手順ガイドなし | 5 |
| 2桁×2桁 その3（2段目に0あり） | 0〜9を使用。2・4問目の下の掛ける数の一の位は0 | 5 |

## 出題範囲

- **2桁×1桁**：10問の被乗数の桁数は、2桁5問・3桁3問・4桁2問の順。1桁の掛ける数は2〜9で、同じ問題や同じ掛ける数が続かないようにする。
- **2桁×2桁 その1**：被乗数は10〜55、掛ける数は十の位・一の位がともに1〜5かつ同じ数字ではないものから出す。
- **2桁×2桁 その2**：被乗数は10〜66、掛ける数は十の位・一の位がともに1〜6かつ同じ数字ではないものから出す。
- **2桁×2桁 その3**：上下とも10〜99。下の掛ける数の一の位は第1・4問のみ0、第1・3・5問は1〜9。その他の一の位は0〜9。第1・4問では部分積を分けず、積の全桁を最初から第1解答行のみに並べる（例：95×20は右から0→0→9→1）。第2解答行・加算線・合計行は非表示とするが、問題と第1解答行の縦位置は変えない。乗数の0と最初に入力する解答0を水色で示す。最初の0だけ入力時に即時判定し、正しい0なら既存の筆算と同じキラキラをその0の下だけに表示し、続く計算中は上2桁と掛ける数の十の位に既存2段目と同じ水色ガイドを表示する（ほかの問題では表示しない）。その後は次へ、誤入力ならバツを表示して0の再入力を待つ。残りの桁は途中判定せず、最後まで入力してから問題全体を判定する。入力順はほかのかけ算筆算と共通で、最後の掛け算で繰り上がりを含む2桁が決まるときは左から右に入力する（49×50の最後の5×4＝20は2→0）。
- 2桁×2桁は、1問の中で一の位の部分積、十の位の部分積、合計を順に入力する。

## ヒントと復習

- 2桁×1桁のヒントは、入力順に下位の桁を示す。2桁×2桁のヒントは、次に入力する1マスを示す。
- ヒント使用、不正解、答え表示を含む初回問題は、初回ラウンドのあとに復習する。
- 復習では報酬・エネルギー・タイムボーナスは増えない。

ヒントを使った問題は自力正解の報酬条件を満たさない。4種ともタイムボーナスの対象である。制限時間と報酬量は [`../game/報酬体系.md`](../game/報酬体系.md) を正とする。
