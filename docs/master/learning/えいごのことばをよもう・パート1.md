# えいごのことばをよもう｜パート１　きほんの名詞　14 words

更新日：2026-11-08
状態：プレビュー実装（iPad Safari／PWA実機確認待ち）

## 学習仕様
- 基本A＋基本Bの14語を学習対象とし、毎プレイ10語を重複なし・完全ランダムに出題する。
- 対象は BED, BOX, CAT, DOG, LEG, MAN, MEN, PIG, SUN, TOP, HAND, MILK, NEST, WIND。
- 単語を最初から全体表示し、文字送りや文字別音声は行わない。
- 「きいてみる」から既存のWeb Speech API設定（en-US、rate 0.85）で発音を聞く。
- 読み上げ開始から約1秒後、イラストと日本語の意味を表示する。
- その後は「もういちどきく」を何度でも使用可能。「いえたよ」で次の単語へ進む。自動採点なし。
- 最後の10問目から既存の育成・報酬導線へ進む。途中終了は未達成。
- 背景・白カード・進捗・操作ボタンのサイズと配置は既存フォニックス単語モードと共通。画面を作り直さず既存部品を再利用。
- 独立した親設定ID `dolch-basic`。既存プロフィールの未設定値はOFFで、報酬と日次ミッションは既存仕組みを使用する。
- 既存の導入5語「フォニックスでよんでみよう」は従来どおり存続する。
- 保存キー・データ構造は変更しない。

## 2026-11-08 追加調整（PR #251）
- 英字の主表示は小文字（例：hand）。すぐ下に小さな大文字（HAND）を併記し、既習の大文字から小文字へ橋渡しする。
- 14語モードでは英字の水色背景を表示しない。既存の導入5語モードのハイライトは変更しない。
- 「きいてみる」で英単語を3回読み上げ、各読み上げ終了から次の開始まで約0.8秒空ける。iPad用に最初の発話はタップ内で開始。
- 3回目の音声が終了し、画像デコードが完了してから、画像と日本語の意味・ルビを一斉表示する。
- 「もういちどきく」も3回の音声再生とし、完了後に画像・意味を一斉再表示する。
- 2つの下部ボタンの高さと下端位置を共通コントロール寸法に統一し、立体的な影を再利用。再生ボタンの右端は中央白カード右端に合わせる。
- 「やめる」、進捗表示の共通配置は変更しない。

## 2026-11-08 再生ボタンの最終調整
- 「もういちどきく」では3回の再読み上げ中も絵・日本語・ルビを消さず、そのまま表示する。
- 再生ボタンは主操作の青とは区別し、淡い水色・濃い文字色・控えめな立体影を使う。高さ・下端・右端位置は維持。

## 2026-11-08 ピッチ聴き比べ（試行UI）
- 14語モードの右上に「声の高さ」の選択メニューを追加。既存の進捗表示・やめるボタンは変更なし。
- Web Speech API `SpeechSynthesisUtterance.pitch` の値を `0.6, 0.8, 1.0, 1.2, 1.4, 1.6, 1.8, 2.0` から選択できる。初期値は1.0。
- モード内でいつでも変更可能で、次に発声する単語から反映。3回の読み上げ途中で変更した場合も、次の発声から反映。
- 選択値は今回保存せず、次回のモード開始時に1.0へ戻る。5語の導入モードは変更しない。
- 実際にどの程度声が変わるかはiPadの音声合成エンジン／選択された音声に依存する。音量は従来どおり最大の1.0。

## 2026-11-08 英字フォント統一（PR #251）
- 「フォニックスでよんでみよう」「えいごのことばをよもう」の両モードに共通する文字単位フォント選択を導入。
- 52文字のうちAndika 49文字、Jost 3文字（大文字Q・小文字t・小文字y）。
- 14語モードは大きな小文字と補助表示の大文字の双方へ適用。5語モードの1文字ずつの表示にも適用。
- 文字に専用のspanを付けて選択するため、1語の途中に現れるt/yにも対応する。
- フォントを読み込むのは対象2モードの英字のみ。日本語の意味とルビ、他モードの書体は変更しない。
