# えいごのことばテスト｜パート１　きほんの名詞　13 words

更新日：2026-11-15
状態：実装仕様確定・コード実装待ち

## 目的と独立性
既存の「えいごのことばをよもう」（13語から毎回10語を学習）は変更しない。別の親設定ID `dolch-basic-test` で音声認識を使わない13問テストを設ける。初期の親設定はOFF。

## 学習対象
`dist/scripts/phonics-words.js` の `basicVocabulary` を正本とし、BED, BOX, CAT, DOG, LEG, MAN, PIG, SUN, TOP, HAND, MILK, NEST, WIND の13語全件を出題する。MENは含めない。絵・日本語・ルビは同モードの既存素材を再利用する。

## UI
- 主題「えいごのことばテスト」、詳細「パート１　きほんの名詞　13 words」。
- 1400×1050の既存ステージ、20種背景、四隅の配置、左上の進捗、左下「やめる」、右上の経過時間を計算モード準拠で共用する。
- 中央の白角丸枠には同じ大きさの13カード。4列×3段と最下段中央1枚（4・4・4・1）。左・右・上・下の位置は既存の大きな白枠に揃える。カードの並びは開始時に独立にランダム化し、そのプレイ中は固定。
- スペル面：大きな小文字（濃ネイビー）＋小さな大文字（グレー）、既存Andika/Jost文字別ルール。
- 意味面：カードの左に折り返さない日本語、右に既存SVG。TOPの意味は「てっぺん／いちばん上」、ルビ既存準拠。
- 意味選択中は、画面上部中央の特別な淡水色カードに**上段大文字／下段小文字**で当該単語を表示。13枚の選択カードを覆わない位置に置く。
- 正解済みカードはスペル面・意味面ともグレーアウト、押下不可。正解前の他カードは位置を移動しない。

## 進行
1. 1/13、未回答の英単語カード、下部に「きいてみる」。音声開始前のカード選択はできない。
2. タップ直後にWeb Speech APIの英語音声3回（en-US、rate=.85、pitch=1.2、volume=1、各再生間0.8秒）を開始。1回目の発話開始からカードを選べる。途中で正解したら残る発話を即時停止する。
3. スペル面正解後、赤い○＋ピンポン0.5秒→意味面へ。不正解はブー＋×0.5秒→同じスペル面で再回答。
4. 意味面も正解なら赤い○＋ピンポン0.5秒→次問のスペル面へ。不正解はブー＋×0.5秒→再回答。
5. 13問終了後、計算結果画面に準じた「えいご n/13」「いみ n/13」表示。選んだ乗り物を育てるCTAから、既存のフォニックス動画終了時と同じサーチライト導線へ。結果画面上にエネルギーを表示しない。
6. 左下「やめる」では途中終了・日次未達成・サーチライトなし。制限時間はなく経過時間のみ表示。

## 採点と保存
- 各語・各段階とも**最初の選択だけで正解した場合のみ1点**。何度間違えても正解するまで再選択可。ただしその段階の点数は0。
- 各語のスペル/意味の誤答回数をそれぞれ計測し、実施単位の結果と累積統計の両方を子どもプロファイル単位で保存。
- 既存のプロファイル・報酬・学習履歴を消去・上書きしない。保存失敗時は問題を続行できるようにし、エラーを記録する。
- 将来の「にがてなことばだけテスト」のために、各語・段階の初回正解状況、誤答回数、実施日時を保持する。

## 受け入れテスト
1. 13語すべてが各面で1回ずつ表示され、MENは出ない。開始後の並びは固定で再起動時は再ランダム化。
2. 最下段1枚が中央、13枚同寸、意味面の日本語は非折返し、既存iPadの1024×665横向きでもカードが重ならない。
3. 「きいてみる」から3回音声。再生途中で選択可能、正解時音声停止。誤答時は音声が続いても構わない。
4. ×・○と音が0.5秒、誤答後同じ段階で再回答できる。完了済みカードは両面でタップ不可。
5. 英語/意味の採点が独立、最初の誤答後に正解してもその段階は0点。13/13満点が表現できる。
6. 途中終了で報酬/日次達成が付かず、終了ボタンからサーチライトへ。既存学習モードや他プロファイルに影響しない。
7. 再読み込み、プロファイル切替後も誤答履歴が独立して残る。既存保存データは無変更。
