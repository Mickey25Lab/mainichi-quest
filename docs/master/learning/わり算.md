# わり算

状態：実装済み  
コード参照先：`dist/app.js` の `makeQuestions`、`makeLongDivisionQuestions`

| モード | 内容 |
| --- | --- |
| わり算計算 | 商と、必要な場合は余りをキーパッドで入力する。10問。 |
| わり算ひっ算 | わり算の筆算の各段階を入力する。10問。 |

## 出題の考え方

- **わり算計算**：0を割る問題、小さい数を大きい数で割る問題、2桁÷1桁（余りあり中心）、余りなし、2桁の商を含む10問を混ぜる。同じ式は1ラウンド内で重複しない。
- **わり算ひっ算**：2桁・3桁の割られる数と2〜9の割る数を使い、商の桁数、0を含む途中計算、余りの有無が偏らない10問を出す。同じ式は1ラウンド内で重複しない。

## ヒントと復習

- ヒントは、商の入力を補助する。答え表示を使う場合は確認画面を経て正解を表示する。
- 初回問題で不正解・ヒント使用・答え表示があった問題は、初回10問の後に復習する。
- 復習では報酬・エネルギー・タイムボーナスは増えない。

初回問題で間違えたものは復習する。ヒント・答え表示、または不正解は自力正解の報酬条件に影響する。両モードはタイムボーナス対象である。
