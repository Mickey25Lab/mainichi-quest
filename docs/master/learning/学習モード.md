# 学習モード

最終更新：2026-10-24  
状態：実装済み

## 共通ルール

- 各モードの初回ラウンドを完了すると、復習対象がある計算モードは復習へ進み、それ以外は結果画面に進む。問題数はモードごとに異なる。
- **計算モード**（わり算、わり算ひっ算、かけ算ひっ算）は、初回ラウンドで不正解・ヒント使用・答え表示があった問題を最後に復習する。復習は、報酬・エネルギー・タイムボーナス・連続正解へ影響しない。
- **すうじあつめ・かずかぞえ**は復習ラウンドを作らない。不正解後も同じ問題でやり直せるが、10問の初回ラウンド終了後は結果画面へ進む。
- ヒント・答え表示を使った問題、または不正解を含む問題は、自力正解の報酬条件に影響する。具体的な報酬量は [`../game/報酬体系.md`](../game/報酬体系.md) を正とする。
- 保護者はモードごとの1日目標回数と、エネルギーのたまりやすさを設定できる。設定値は子どもプロフィールごとに保存する。
- タイムボーナスの対象は計算モードの一部だけで、すうじあつめ・かずかぞえ・フォニックスは対象外である。詳細は [`../game/報酬体系.md`](../game/報酬体系.md) を正とする。

## 日次ミッションの最終完了判定（ワークストリーム2・PR3）

- プロフィール別・JST日付別・有効な目標回数別に、プレイ前とプレイ完了時の残り回数を判定する。
- **今回の1回で** 全有効モードの残り回数が0になる場合だけ「本日最後のミッションを完了した」という内部判定を成立させる。すでに全完了の状態での自由プレイ、対象外モード、目標回数0件は対象外。
- 通常学習は全問題（必要な復習を含む）の完走後、フォニックスは従来の日次完了計上地点で判定する。途中終了は計上しない。
- プレイ開始時のプロフィールとJST日付が完了時と異なる場合は、そのプレイを当日ミッションに計上しない。翌日にまたがったプレイを翌日の初回達成として誤認しない。
- 判定結果は内部メモリのみ。保存済みの日次達成回数以外に新しい永続フラグを作らず、受け取り画面・報酬・終了導線は本PRでは変更しない。

コード参照：`dist/app.js` の `beginDailyMissionAttempt`、`dailyMissionCompletionTransition`、`completeDailyMissionRound`。テスト：`tests/daily-final-mission.test.cjs`。
