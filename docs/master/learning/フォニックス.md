# フォニックス

状態：実装済み（動画再生・報酬連携）、運用上の確認事項あり  
コード参照先：`dist/app.js` の `phonicsYoutubeLessons`、`phonicsGrowthAmounts`

| モード | 範囲 |
| --- | --- |
| パート1〜5 | A〜F、G〜K、L〜P、Q〜U、V〜Z |
| まとめ | A〜Z |

## 流れ

1. モード選択でパートまたはまとめを選ぶ。
2. 導入画面のあと、YouTube動画を指定区間ごとに再生する。各文字は聞く区間と練習する区間を順に再生する。
3. 動画を最後まで完了すると、成長させる発見済みの車種を選ぶ。
4. 選んだ車種がなかよし前なら「なかよし」、なかよし後なら「エネルギー」を加算する。

動画の区間・YouTube上の注意事項は [`../../phonics-youtube-poc.md`](../../phonics-youtube-poc.md) と [`../../phonics-segments/README.md`](../../phonics-segments/README.md) を正とする。各動画完了後の成長量は、通常は「なかよし +5」または「エネルギー +25」、保護者設定が「ほぼ0」の場合は「なかよし +1」または「エネルギー +5」。フォニックスはタイムボーナス・復習ラウンドの対象外である。

YouTubeの子ども向け self-designation は公開運用時に必要な確認事項であり、実装だけでは完了しない。
