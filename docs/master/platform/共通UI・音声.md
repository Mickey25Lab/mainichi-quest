# 共通UI・音声

状態：実装済み（一部既知課題あり）  
コード参照先：`dist/app.js`、`dist/styles.css`

## 共通UI

アプリは、トップ、モード選択、問題、復習への切替、報酬、結果、コレクションの画面で構成する。フォニックスは導入画面と動画画面を追加で使う。

問題画面には、進捗、やめる、ヒント／答え、BGM切替を置く。60秒間操作がない場合は、すうじあつめでは次の数字カード、かずかぞえでは正しい数字、それ以外のモードではヒントボタンを指して操作ガイドを出す。子どもが操作を再開するとガイドは消える。

「やめる」は確認画面を経てモード選択へ戻る。結果画面では、今回の獲得物・進捗・正解数・所要時間を見せる。

## 保護者向けの共通画面

- プロフィール切替：遊ぶ子どもを選ぶ。
- 保護者設定：プロフィールごとのモード、日次目標、エネルギー設定、フリープレイ設定を扱う。
- 診断・リセット：保護者向けの管理画面で扱う。リセットの対象と保護原則は [`プロファイル・保存・復元.md`](プロファイル・保存・復元.md) を正とする。

## 音声

問題プレイ中はBGMを再生し、問題間で再生位置を維持する。画面ごとにトップ／フォニックス導入、問題・報酬、コレクションのBGMを使い分ける。

BGMのON／OFFは端末に保存され、プロフィールを切り替えても同じ設定を使う。BGMをOFFにしても、正解・不正解・報酬・終了などの効果音はOFFにしない。報酬表示中はBGMを止めずに音量を下げる。

効果音の音量バランスは実機での検証が未完了であり、[`../planning/改善バックログ.md`](../planning/改善バックログ.md) のMQ-005で管理する。
