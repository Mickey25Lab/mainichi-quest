# 共通UI・音声

状態：実装済み（一部既知課題あり）  
コード参照先：`dist/app.js`、`dist/styles.css`

## 共通UI

問題画面には進捗、やめる、ヒント／答え、BGM切替を置く。60秒無操作時は、モードに応じた操作ガイドを表示する。結果画面では獲得物・進捗・正解数を見せる。

## 音声

問題プレイ中はBGMを再生し、問題間で再生位置を維持する。BGMのON／OFFは端末に保存され、効果音はOFFにしない。報酬表示中はBGMを止めずに音量を下げる。

## 既知課題

iPad Safariで、放置後・復帰時に画面が左上起点で異常拡大表示される課題が未解消。修正案は [`../planning/改善バックログ.md`](../planning/改善バックログ.md) で管理する。

## トップ画面の保護者・開発者向けダイアログ（2026-10-25）

- 歯車の設定名称は「開発者ツール」。開発者ツールではQAモード・当日コレクション再閲覧・開始時ムービー再再生・現プレイヤーのデータ削除を表示する。画面拡大診断、BGM消失診断、累計ポイント診断は画面上では非表示とし、内部の診断機構・保存形式はこのUI変更では変更しない。
- PIN入力欄と新規プレイヤー名入力欄は薄い水色背景・濃紺文字。両方のPINテンキーにある「クリア」「1文字消す」は白背景・グレー枠で、取消ボタンは従来のグレー。
- データ削除ボタンは白背景・赤文字・赤枠。削除前の確認手順とプレイヤーデータの保存・リセット処理は維持する。
- トップ画面のプレイヤー選択、開発者ツール、保護者PIN・設定などのモーダルは背景の暗い領域をタップすると、開いているダイアログを閉じてトップ画面に戻る。カード内部のタップでは閉じない。保護者設定の未保存編集内容は保存しない。
