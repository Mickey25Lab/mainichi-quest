# 共通UI・音声

状態：実装済み（一部既知課題あり）  
コード参照先：`dist/app.js`、`dist/styles.css`

## 共通UI

問題画面には進捗、やめる、ヒント／答え、BGM切替を置く。60秒無操作時は、モードに応じた操作ガイドを表示する。結果画面では獲得物・進捗・正解数を見せる。

## 音声

問題プレイ中はBGMを再生し、問題間で再生位置を維持する。BGMのON／OFFは端末に保存され、効果音はOFFにしない。報酬表示中はBGMを止めずに音量を下げる。

## 既知課題

iPad Safariで、放置後・復帰時に画面が左上起点で異常拡大表示される課題が未解消。修正案は [`../planning/改善バックログ.md`](../planning/改善バックログ.md) で管理する。
