# マイクエ 全体仕様

最終更新：2026-10-24  
状態：実装済み仕様を最新コードへ照合中

## この文書の役割

マイクエは、日々の学習を「のりものとの出会い・育成・コレクション」へつなげる子ども向け学習アプリである。
この文書は機能同士の関係と、正式仕様の読み方を扱う。個別の数値・画面・操作は各専門仕様を正とする。

## 機能のつながり

`学習モード` → `正解・復習` → `報酬進行` → `コレクション` → `ポイント・レベル` の順で、子どもの1回の体験が構成される。

- 学習内容・共通のプレイ規則：[`learning/学習モード.md`](learning/学習モード.md)
- 報酬・車種・コレクション・アイテム・レベル：[`game/`](game/)
- 子どもプロフィール、共通画面、音、保存・復元：[`platform/`](platform/)
- 実装済みではない計画・改善候補：[`planning/`](planning/)

## 状態の表記

- **実装済み**：現在の `dist/` のコードで動作するもの。
- **確定済み・未実装**：方針は決まっているが、コードには未実装のもの。
- **検討中**：方向性や候補であり、実装仕様ではないもの。数値を推測して補わない。

## 正本の優先順位

動作上の最終的な正本はコードである。MDとコードに差が見つかった場合は、勝手にどちらかへ合わせず、差分をPRで報告して判断を仰ぐ。ゲームバランスの値は、人が確認しやすいようMDにも掲載し、各表にコード上の参照先を付ける。
