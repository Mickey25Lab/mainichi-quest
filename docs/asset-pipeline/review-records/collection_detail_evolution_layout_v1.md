# コレクション詳細・進化レイヤー配置仕様 V1

## 適用範囲

- コレクション詳細画面の20車種共通レイアウト
- 基準キャンバス：1400×1050
- 車種別の座標補正は行わない
- 背景には暗色オーバーレイを重ねない
- 左右の車種移動ボタンは置かず、横スワイプで移動する

## 表示状態

| 進行状態 | 表示 |
| --- | --- |
| 未発見 | 車種背景だけ |
| 発見済み・仲良し前 | 車種ロゴ、グレースケール乗り物、黒いロボットシルエット |
| 仲良し達成 | 車種ロゴ、カラー乗り物、黒いロボットシルエット |
| ロボット獲得 | 車種ロゴ、カラー乗り物、カラーロボット |
| スーパーロボット獲得 | 車種ロゴ、乗り物、ロボット、スーパーロボットの三体表示 |
| スペシャル装備獲得 | 三体表示の右端を装備付きスーパーロボットへ交換 |

マスターメダル表示、スペシャル装備名、将来のモード切替は後続工程とする。

## 共通レイヤー

### 車種ロゴ

- `left: 3.4%`
- `top: 3.2%`
- `width: 36%`

### 二体表示

- レイヤー領域：`left/right 7.5%`, `top 19%`, `bottom 6.8%`
- 列：乗り物 `1fr`、中央 `13%`、ロボット `1fr`
- シェブロン：`left 46.25%`, `bottom 36%`, `width 7.5%`, `height 12%`
- ラベル幅：スロットの `39.2%`
- ラベル文字：18px、折り返しなし

### 三体表示

- レイヤー領域：`left/right 2%`, `top 13%`, `bottom 3.5%`
- 各スロット：幅33%、高さ72%
- 乗り物：`left -3.5%`, scale `70%`
- ロボット：`left 21%`, scale `90%`
- スーパーロボット：`left 56%`, scale `200%`, Y `+8%`
- シェブロン1：`left 22.8%`, `bottom 28%`
- シェブロン2：`left 49.7%`, `bottom 28%`
- 短いラベル幅：スロットの `49%`
- スーパーロボットラベル幅：スロットの `70%`
- 乗り物ラベル中心：`left 43.5%`
- ロボットラベル中心：`left 47%`
- スーパーロボットラベル中心：`left 60.5%`
- ラベルは同じY位置、折り返しなし

## 画像処理

- 仲良し前の乗り物：CSS `grayscale(1)`
- 未獲得ロボット：CSS `brightness(0)`
- グレースケール版・黒シルエット版の派生画像は作らない
