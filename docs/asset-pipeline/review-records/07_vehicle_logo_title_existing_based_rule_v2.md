# 車種名英語ロゴ 現行ベース統一ルール v2

## 1. 方針

現行20車種のロゴデザインを原型とする。
車種固有のアイコン、配色、メタリック表現、スピード感はシリーズの魅力として維持する。
全車種を同じプレートや同じアイコンへ置き換えず、制作上の共通骨格と描画品質だけを統一する。

先に作成した `A CHROME SPEED`、`B ARMOR PLATE`、`C HERO CREST` は正式方向として採用しない。

## 2. 現行20種の計測結果

`alpha < 16` を除外した外接矩形では、次の範囲だった。

- 横幅：1100～1202px
- 全体高：137～226px
- 縦中心：597～651px
- キャンバス：全車種1254 × 1254px / RGBA

横幅はすでにおおむね統一されている。
見た目のばらつきは、文字高、アイコン高、縦位置、末尾装飾、色面積の差から生じている。

## 3. 固定する共通骨格

### 3-0. キャンバスと表示領域

- キャンバスは `1254 × 320px` とする。
- RGBA、背景完全透過とする。
- ロゴ全体の最大表示領域は `1160 × 220px` とする。
- ロゴ全体をキャンバスの x=627、y=160 を基準に光学中央配置する。
- 左右余白47px以上、上下余白50px以上を基本とする。
- `alpha < 16` は機械的正規化時に完全透明化する。

### 3-1. 英語表記

- `vehicle_master.csv` の英語名を正とする。
- 現行ロゴと同じく、単語間の空白を見せないPascalCase表記を基本とする。
- 例：`PatrolCar`、`ConcreteMixer`、`KindergartenBus`。
- 大文字・小文字の比率、文字間隔、単語間隔を全車種で同じ規則にする。

### 3-2. タイポグラフィ

- 太いコンデンス系サンセリフを共通母体にする。
- 右方向への傾斜角を全車種で固定する。
- 大文字高、小文字高、ベースライン、文字間隔を共通化する。
- 長い名称は文字高を小さくせず、横方向の圧縮と字間調整で共通幅へ収める。
- 文字ごとに異なる書体、極端な太さ変更、車種別の輪郭形状変更は行わない。

### 3-3. 文字のメタリック表現

- 文字面は白～シルバーを基本とする。
- 上部ハイライト、中間の銀色、下部の薄い影という共通グラデーションを使う。
- 外周は濃紺または黒の太縁、その内側に車種色の細縁を置く。
- 立体影は右下方向へ統一し、距離・濃度も固定する。
- 発光は輪郭をぼかさない強さに抑え、文字の読みやすさを優先する。

### 3-4. 共通レイアウト

- 構成は「左アイコン＋英語名＋共通アクセントライン＋共通ダブルスラッシュ」とする。
- 文字列の光学中心をキャンバス中央付近へ置く。
- ロゴ全体の基準中心Yは630px付近とし、通常差を±12px以内にする。
- 安全余白は左右32px以上を確保する。
- 外接矩形は最大1160 × 220pxに収める。
- 文字本体の見た目の高さを共通化する。アイコンや翼などの突起だけは基準高からはみ出してよい。
- 縦位置は外接矩形だけで決めず、文字本体のベースラインと光学中心で合わせる。

## 4. 残す車種ごとの個性

### 4-1. 左アイコン

- 現行の車種別モチーフを残す。
- パトカーの星、消防車の炎、救急車の医療記号など、既存の意味を維持する。
- アイコンの外接サイズ、文字との間隔、メタリック仕上げの強さだけを共通化する。
- アイコンは文字本体より極端に大きくしない。特殊形状の突起は許容する。

### 4-2. 車種色

- 各車種の現行主色を残す。
- 1車種あたり主アクセント1色、補助色は必要な場合だけ1色までとする。
- 文字面の65%以上は白～シルバーに保つ。
- 主アクセントは、アイコン、内側の細縁、下部ベベル、右端装飾を中心に使う。
- 補助色はアイコン内部または小さなハイライトに限定し、ロゴ全体へ散らさない。

### 4-3. 右端装飾

- 全車種で同じ形状のダブルスラッシュを使う。
- 本数、傾斜角、線の太さ、2本の間隔、文字との間隔、立体影を固定する。
- 色だけを車種ごとの主アクセント色へ変更する。
- タイヤ、荷物、翼、機体などの車種固有モチーフは右端へ置かず、左アイコンへ集約する。

### 4-4. 背景とアクセントライン

- ロゴ全体を囲う背景プレートや背景帯は使わない。
- 背景は完全透過とする。
- 文字直下に全車種共通形状の細いアクセントラインを置く。
- アクセントラインは右端のダブルスラッシュへ視覚的につながる構造とする。
- アクセントラインの色だけを車種ごとの主アクセント色へ変更する。
- 読みやすさは背景帯ではなく、文字に密着した共通の濃紺外縁と控えめな右下影で確保する。

## 5. 統一時に優先して修正する項目

1. 20車種で共通の文字母体へ統一する。
2. 文字本体の高さ、傾斜角、ベースラインをそろえる。
3. 左アイコンの占有サイズと文字との間隔をそろえる。
4. 白～シルバーと車種色の面積比をそろえる。
5. 外縁、内縁、立体影、発光の太さと方向をそろえる。
6. 右端装飾の角度、線幅、文字との距離をそろえる。
7. 最後に1254 × 1254px上で光学中心と占有感を調整する。

## 6. デザイン比較に使う代表車種

最初の比較では、現行デザインの差が分かりやすい次の3車種を使う。

- `PatrolCar`：大きな左アイコンと短い名称
- `ConcreteMixer`：低い文字高と横長構成
- `KindergartenBus`：長い名称と多色アクセント

この3種で、現行の魅力を維持したまま共通文字、共通縁取り、共通立体感、共通レイアウトが成立することを確認してから20車種へ展開する。
