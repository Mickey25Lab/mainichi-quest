# 車種名英語ロゴ 統一コンセプト v1

## 目的

`07_vehicle_logo_title` の20車種を、車種ごとの個性を残しながら同一シリーズに見えるロゴへ統一する。
この段階では正式PNGを置き換えず、代表3車種による方向性比較だけを行う。

## 全案共通ルール

- 英語名は `vehicle_master.csv` の `vehicle_name_en` を正とする。
- 表記は全車種で大文字（ALL CAPS）に統一する。
- 1行組み、右上がりのイタリック、太いコンデンス系サンセリフを使用する。
- 文字の基準高、ベースライン、傾き、縁取り、立体影の方向を全車種で固定する。
- 長い名称も高さを変えず、字間と横方向の圧縮だけで共通表示幅に収める。
- 外周は濃紺～黒の二重縁、立体影は右下方向に固定する。
- 車種色は1色を主アクセントとして使用し、文字の可読性を損なう多色グラデーションは使わない。
- 左右の装飾は共通形状・共通位置とし、車種固有の絵アイコンは方向性決定後に別ゲートで検討する。
- 透明背景を前提とし、発光や影を含めても安全余白内に収める。

## 比較する3案

### A案：Chrome Speed

- 銀白色の文字面を主体にする。
- 車種色は下線と末尾3本のスピードバーだけに使う。
- 現行ロゴの勢いを残しつつ、最も整理された案。

### B案：Armor Plate

- ガンメタルの共通プレート内に文字を置く。
- 左端の六角チップ、上下の細いラインに車種色を使う。
- シリーズ統一感が最も強く、UI上で背景に左右されにくい案。

### C案：Hero Crest

- 銀白色の文字面と車種色の下部フェードを組み合わせる。
- 左端に共通の小型クレスト、末尾に共通の二重ウイングを置く。
- 子ども向けの明るさとヒーロー感が最も強い案。

## 代表3車種

- PATROL CAR：短い名称の基準
- CONCRETE MIXER：中程度の名称の基準
- KINDERGARTEN BUS：長い名称の基準
