# フォニックス動画 技術PoC

このPoCは、YouTube IFrame Player API を利用して、子どもが自分で再生を開始した動画を指定位置で止め、短い発話時間の後に再開できるかを確認するためのものです。

## 対象

- 動画: `ChqnN3cKzXQ` — ABC Phonics Chant for Children
- 画面: モード選択の「フォニックス（動画）」
- 技術検証区間: 0:10 から 0:20 まで
- シーケンス:
  1. 0:10〜0:15 を音ありで再生
  2. 0:10 に戻り、0:10〜0:15 を音なしで再生
  3. そのまま 0:15〜0:20 を音ありで再生
  4. 0:15 に戻り、0:15〜0:20 を音なしで再生
  5. 0:20 で終了
- 音なし区間は YouTube IFrame Player API の mute/unMute を使用し、動画自体は再生状態を維持したまま区間を切り替える

YouTube プレーヤーの上には要素を重ねません。モード選択表示中にプレーヤーを先行準備し、準備完了までは「フォニックス（動画）」を押せない状態にします。準備完了後の「フォニックス（動画）」タップのユーザー操作中にそのまま再生開始するため、追加の「はじめる」操作は原則不要です。ブラウザ側がそれでも再生を拒否した場合だけ「再生する」をフォールバック表示します。プレーヤーの標準シークバー等は公式の `controls=0` で非表示にします。YouTube側が表示する中央の再生アイコン、リンク共有UI、タイトル・ブランド表示や「その他の動画」等の関連動画UIは、公式 IFrame Player API / embed パラメータでは完全非表示にできません（`rel=0` は関連動画を完全に消す設定ではありません）。規約外のCSS被覆やプレーヤーへのオーバーレイは行いません。バックグラウンド化、PWA の復帰後は自動再開しません。シークで既に通過した停止位置へ戻っても、同じ位置を二重に停止しません。

## 明示的に含めないもの

視聴に結びつく星、エネルギー、ポイント、コレクション、保存、完了報酬、または解放要素はありません。最後は「おわる」でモード選択へ戻ります。

## 子ども向け self-designation

実装は `youtube-nocookie.com` を使いますが、これは self-designation の代替ではありません。本番公開前に、運用者が YouTube の child-directed API client 向け手順で、このサイト/アプリを child-directed として Google に通知する必要があります。埋め込み先が子ども向けの場合は、Privacy Enhanced Mode を使っていても self-designation が必要です。

- [YouTube: Embed videos & playlists](https://support.google.com/youtube/answer/171780)
- [YouTube Developer Policies: Child-Directed API Clients](https://developers.google.com/youtube/terms/developer-policies#j-child-directed-api-clients)

この通知に必要なアカウント設定はリポジトリのコードから自動化せず、公開責任者が本番ドメインと法的な対象年齢を確認して行います。

## 確認方法

1. モード選択から「フォニックス（動画）」を開く。
2. 「フォニックス（動画）」はプレーヤー準備完了後に押せるようになり、その1回のタップだけで 0:10 から再生が始まることを確認する。ブラウザに拒否された場合のみ「再生する」が表示される。
3. 0:10〜0:15 が音ありで流れることを確認する。
4. 0:15 到達後に 0:10 へ戻り、0:10〜0:15 が音なしで流れることを確認する。
5. 0:15 到達後、そのまま 0:15〜0:20 が音ありで流れることを確認する。
6. 0:20 到達後に 0:15 へ戻り、0:15〜0:20 が音なしで流れることを確認する。
7. 0:20 で終了し「おわる」が表示されることを確認する。
8. シークバー等の標準コントロールが常時表示されないことを確認する。中央の再生アイコンやリンク共有UIはYouTube側UIのため、表示される場合がある。
9. 「おわる」でモード選択へ戻り、もう一度フォニックスを選んでも追加タップなしで開始できることを確認する。

自動確認は `node --test tests/phonics-youtube-poc.test.cjs` で行えます。iPad相当の 834×1112・タッチ有効 viewport で、開始、10〜15秒/15〜20秒の音あり・音なし切替、終了、再入時のPlayer再preloadをモックした IFrame Player API で確認します。
